4. Detailed Round Implementations

Round 1: Aptitude & Logic (aptitude.html)

  • Format: 30 Multiple Choice Questions (MCQs) with options A, B, C, D.
  • Timer: 30-minute global countdown timer with auto-submission upon expiry.
  • Scoring: Exact deterministic numerical calculation (1 mark per correct answer, 0 for wrong/skipped).
  • Dedicated Result Scorecard: Instant post-round screen displaying Total Questions, Attempted, Correct, Incorrect, Skipped, Accuracy %, Time Analysis, Topic-wise breakdowns, and step-by-step derivations.

Round 2: Technical Architecture (technical.html)

  • Format: 30 structured conceptual & system design questions.
  • AI Evaluation: Evaluates candidate answer against expected concepts, categorizing concept coverage, scores out of 10, correct points, missing concepts, technical mistakes, and improvement plans.
  • Voice Support: Full Web Speech Recognition dictation and SpeechSynthesis reading.

Round 3: Coding / DSA — C++ Only (coding.html)

  • Language: Fixed permanently to C++ ONLY.
  • Starter Template: Strictly clean starter code without exposing reference solutions: 
    #include <iostream>
using namespace std;

int main() {
    // Write your code here

    return 0;
}
  • Approach Explanation: Dedicated candidate approach box to articulate complexity tradeoffs ($O(N)$ time/space).
  • 3-State Verdicts: ✅ Correct (88-98 pts), 🟡 Partially Correct (50-65 pts), and ❌ Incorrect (15-30 pts).
  • State Isolation: Independent state tracking across all 30 problems preserving typed code when switching questions.

Round 4: HR / Behavioral (hr.html)

  • Format: 30 behavioral/leadership scenario questions.
  • STAR Analysis: AI evaluation structured against Situation, Task, Action, and Result components with KPI metrics.
